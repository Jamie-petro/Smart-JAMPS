# 3-minute demo script

1. **(0:00) Problem.** "An arts collective wants to light up a void deck. Who do they ask first? Which grant? Today that's ten agency websites."
2. **(0:20) Layer 1 — Spaces.** OneMap of Singapore, 12 real candidate spaces (void deck, plazas, parks, Kampong Glam streets, a heritage station, a site with an unknown owner). Click **Void deck, Blk 177 Toa Payoh Central** → *Use this space*.
3. **(0:45) Layer 2 — Proposal.** Read the case: lantern workshop → light installation → acoustic set → drinks stall.
   - **Guidelines**: point at the *verified* one — Bishan-Toa Payoh TC does not permit variety shows at void decks, so keep it acoustic or use the open space (source link).
   - **Whom to approach, in order**: Town Council first, then IMDA Arts Entertainment Licence (start by = 40 working days, ~9 weeks with CNY, verified), then police notification (7 days) if exempt. Each step has why + source + badge.
4. **(1:30) What-if.** Tick **Charge for tickets** → a new step appears (declare ticketed event) and the Lively Places Fund criterion "not a commercial event" flips to *not met* with a real improvement: make it free.
5. **(1:50) Switch site.** Back to map → **Bishan-Ang Mo Kio Park** → workplan swaps Town Council for NParks; park-specific guidelines appear. Try **Dakota Crescent** → "identify the land owner first" gap.
6. **(2:10) Funding.** Lively Places Fund (verified: up to $5,000, non-commercial, public access) vs NAC grant (assumption). Overlap warning: LPF excludes projects funded by other agencies.
7. **(2:30) Layer 3 — Render.** *Visualize this event* → AI concept image, labelled "AI-generated concept, not a design or approval".
8. **(2:45) Honesty.** "Still to check" list = our gaps. Every badge is verified / assumption / gap. We never say "you qualify".
